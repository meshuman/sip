# ShareBar

Quiet, square buttons for sharing a piece, a maker or an owner's record, with the short link shown in the registry face.

- Every piece has a short link built from its registry number (`/p/PTN-MT-26-0142`). It reads well when spoken, printed and pasted, and it is what the catalogue card's QR code opens.
- Order the buttons by where the audience actually shares: Copy link, WhatsApp, Viber, Email. Text labels only, no brand logos.
- "Copy link" confirms in place with "Link copied". Never use a pop-up.
- Place the bar under the ExhibitionHero and on the owner's record.
