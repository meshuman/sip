# Patterns

- **iconometric-grid:** the thangka painter's proportion grid, drawn as gilt hairlines on lokta. Use it behind the seal on share cards, on the inside of packaging, and on empty states such as "This room is being hung". Never put it behind running text.
- **lokta-fibre:** a fibrous paper texture (512px tile) for large lokta grounds in print and packaging. On screen, use it at most on one band per page, behind the CollectionRoom header or the footer.
