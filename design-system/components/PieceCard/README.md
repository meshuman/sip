# PieceCard

One piece in a collection: a 4:5 plate, the piece name, maker · place · material, then registry number and price on a hairline.

- Place cards inside `.sp-gallery` (or a CollectionRoom). Price lines stay level across a row even when titles run to two lines.
- Plates are square-cornered, with no hover zoom. The title turns malachite on hover.
- A sindur "One of one" flag sits top-left, only on true single pieces.
- Never show a piece without its maker.
- Wrap compound names in `.sp-nb` (`Shakyamuni, <span class="sp-nb">earth-touching</span>`) so they never break at the hyphen.
- Until photography exists, use the plates in the Plates asset group.
