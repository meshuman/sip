# Logos

The wordmark and seal are outlined from Rozha One, so they render the same everywhere without the font installed.

| File | Use |
|---|---|
| sipa-lockup-ink / -paper | The primary lockup: seal, wordmark and सीप. Use it for the site header, catalogue card front and packaging. |
| sipa-wordmark-ink / -paper | Wordmark alone, where the seal already appears nearby. |
| sipa-devanagari-ink / -paper | सीप alone, for Nepali-first contexts and the second voice. |
| sipa-seal-gilt | The registry seal, outline. It means *recorded*. Use it only next to a registry number or as the brand favicon. |
| sipa-seal-owned | The filled seal, for an owner's record and share cards after purchase. |

Inks: -ink files are #1c1c19 (ink, light theme). -paper files are #f7f6f2 for dark grounds, except the lockup's gilt, which goes lighter (#d4b06a) on dark. The seal's gilt is #987431, with the glyph in gilt-ink #6e521c.

Clear space around any mark equals the seal's inner ring diameter. Never set the wordmark in a live font, recolour it outside these inks, or put it on a photograph.
