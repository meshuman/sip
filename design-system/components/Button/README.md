# Button

A square button in malachite, the only colour that means "you can press this".

- **Primary** (`.sp-btn`): one per view. The buying action reads "Make it yours" and carries the price in the registry face.
- **Quiet** (`.sp-btn--quiet`): secondary actions such as "Watch the making" or "View in 3D".
- **Disabled**: a sold piece reads "Recorded to its owner", never "Sold out".
- **Text link** (`.sp-link`): for moving between acts, such as "Meet Raju Shakya".

Square corners (radius-0), 48px minimum height. Labels are verbs and say exactly what happens. Never use gilt or sindur for a button.
