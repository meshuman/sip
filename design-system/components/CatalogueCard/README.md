# CatalogueCard

The printed card that ships with every piece: a single 125 × 175 mm lokta card, printed front and back.

- **Front:** the brand line, the registry seal, the piece name, a short gilt rule, maker and place, material and days, dimensions, and the registry number at the foot. It is set centred, like a gallery label mounted on the wall.
- **Back:** meaning, placement and care in one or two sentences each, then a QR code that opens the owner's record, closed by the origin line.

Every field comes from the same record as the piece page, so print and web never disagree. The QR in the preview is a placeholder pattern.

Print gilt as foil or a metallic ink, never flat yellow. On screen, the card takes shadow-lift, the system's only shadow. A print-ready PDF template is in the Print asset group.
