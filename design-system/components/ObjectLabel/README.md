# ObjectLabel

The facts of a piece in a fixed museum-label order, on paper with hairline rows.

Order is fixed: title, then maker · place · year, then Material, Size, In the hand, Edition, then the registry number and price. Consumers provide every field; leave a row out rather than writing "N/A".

- Size is always in the registry face: H · W · D in cm, then weight.
- "In the hand" is days of work and the span it covers.
- The registry number is gilt-ink; the price is ink.
- The same fields feed the printed catalogue card and the structured data, so they must never be rewritten per page.
