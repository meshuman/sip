# ArtisanByline

The maker's name, place and own words, with their portrait inside the gilt halo.

- Consumers provide a workshop portrait (hands or face, never a studio headshot), the full name, and the place, which is shown in lapis.
- Add one or two facts of lineage or years at the bench.
- Add a quote in the maker's own language with an English line beneath. It hangs from a large gilt quotation mark, never a side bar.

If there is no portrait yet, the halo holds the first Devanagari syllable of the name. Never invent quotes. Record them on the filming day.
