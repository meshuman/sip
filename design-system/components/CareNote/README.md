# CareNote

Care instructions as a short ruled list, keyed by how often. Use it on its own where no kit ships, and as the short form on cards. Where a care kit ships with the piece, use CareKit instead, which shows the equipment as well as the steps.

Rows go from most to least frequent (Weekly, Yearly, Moving), and end with a "Never" row in sindur. One instruction per row, starting with a verb. The material name in the label matches the care topic page it links to (metal, stone, wood, painted cloth, paper).
