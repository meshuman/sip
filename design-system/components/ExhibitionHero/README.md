# ExhibitionHero

Opens every piece page the way a gallery wall opens a room: a large plate on the left, and the piece's wall text on the right.

Content, top to bottom:
1. The room line (collection name) and the piece's place in it.
2. The piece name in display-xl.
3. Maker and place in one sentence with the days.
4. A two-sentence lead.
5. The registry seal.
6. The primary action with its price, and "Watch the making".

The plate carries a caption in the registry face saying when and how it was shot. On phones it stacks: plate first at 4:5, then the text. Use one hero per page. Never put text over the photograph.
