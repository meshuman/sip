# PlacementCompass

Shows which direction a piece customarily faces, and the height and room it suits.

Consumers provide the facing direction (the compass highlights it in malachite), a height line and a room line. Always keep the closing note that this is custom, not a promise. Never claim a placement brings luck, wealth or health.

For paintings (thangka, Mithila), "Facing" becomes the wall the painting hangs on, and add a "Light" row: no direct sun.
