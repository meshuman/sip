# Icons

Fourteen line icons drawn for Sīpa's subject: a 24px grid, 1.5px stroke, square caps and mitre joins, in ink #1c1c19.

To recolour, inline the SVG and set `stroke="currentColor"`, or use the file as a CSS mask. Always pair an icon with a text label. Icons never stand alone as buttons, except the 3D and film controls on a stage.

| Icon | Means |
|---|---|
| compass | Where to place it |
| care-brush | How to care for it |
| oil-flask | Care kit, wood oil, refills |
| maker-hand | The maker |
| record-seal | The registry record |
| view-3d | Turn in 3D |
| film | Watch the making |
| place-pin | Where it was made |
| dimensions | Size and weight |
| share | Share |
| qr-record | Scan to the owner's record |
| gift | Send as a gift |
| making-days | Days in the hand |
| altar-lamp | Placement on an altar or shrine |
