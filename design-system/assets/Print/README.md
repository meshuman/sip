# Print

- **catalogue-card-125x175.pdf:** a two-page template for the catalogue card (front, then back) at 125 × 175 mm with no bleed, filled with the example piece.

Before printing:
- Add 3 mm bleed.
- Set gilt as foil or a metallic spot ink.
- Print on lokta of 120 gsm or heavier.
- Replace the placeholder QR code with the piece's real code.
